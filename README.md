# DocStamper

一個純前端的 PDF 電子簽章工具，可在瀏覽器中將印章圖片蓋到 PDF 指定位置，並下載簽署後的 PDF。

## 功能特色

- 上傳 PDF 文件並逐頁預覽
- 支援三種印章：
  - 公司大章
  - 公司小章
  - 發票章（可選）
- 可在頁面上新增印章後拖曳移動
- 可切換縮放模式調整印章大小
- 可新增任意大小的手簽框，直接在框內手寫簽名
- 手簽框可清除簽名後重新簽署
- 可於不同頁面分別放置印章
- 下載合成後的簽署 PDF

## 技術說明

本專案目前為單一 `index.html`，以 CDN 載入前端函式庫：

- `pdf.js`：PDF 預覽與頁面渲染
- `pdf-lib`：將印章嵌入 PDF 並輸出新檔
- `Tailwind CSS`（CDN）：介面樣式

## 使用方式

1. 開啟 `index.html`（可直接雙擊，或用本機靜態伺服器開啟）
2. 上傳 PDF
3. 上傳印章圖片（PNG/JPG）
4. 點擊「添加大章 / 添加小章 / 添加發票章」
5. 若需要手寫簽名，點擊「添加手簽框」，拖曳移動到目標位置，並在框內簽名
6. 必要時切換縮放模式調整印章或手簽框大小；手簽框可按清除重新簽名
7. 切換頁面重複操作
8. 點擊「下載簽署後 PDF」

## 注意事項

- 發票章為 optional，不上傳不影響其他功能
- 未放置任何印章且未完成任何手寫簽名時，無法輸出簽署 PDF
- 圖片格式僅支援 `PNG`、`JPG/JPEG`
- 實際輸出位置會依畫布與 PDF 座標轉換計算
